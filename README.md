# Pig Inspection – downloads

The newest version of the Pig Inspection app. These links always download the latest release.

## 📱 Android phone

**[Download PigInspection.apk](https://github.com/Waynemcfarlane81/pig-inspection-downloads/releases/latest/download/PigInspection.apk)**

1. Open this page on the phone and tap the link above. `PigInspection.apk` downloads.
2. Open the download and tap **Install**. If asked, allow Chrome to install apps.
3. Open **Pig Inspection** and sign in. The app tells you when a newer version is ready.

## 💻 Windows computer

**[Download PigInspection-Setup.exe](https://github.com/Waynemcfarlane81/pig-inspection-downloads/releases/latest/download/PigInspection-Setup.exe)** (Windows 10 or 11)

1. Click the link above. `PigInspection-Setup.exe` downloads (about 77 MB).
2. Open it. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway** (the installer isn't paid-for code signed).
3. Choose where to install and click **Install**. A **Pig Inspection** shortcut is added to the desktop and the Start menu.
4. Open it and sign in with your name and PIN. It uses the same records as the phones.
5. **Help → Check for updates** offers new versions; it also checks by itself when open.

Reading labels with the camera and location alerts work on the phone only.
